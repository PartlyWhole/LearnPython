# Canonical Concept Vocabulary

Seed list of shared concept IDs, grouped by `category`. Course graphs should map onto
these IDs; add new ones (flagged `"new": true`) only when nothing fits.

## environment
- `python_setup` — installing Python, running the interpreter
- `repl` — interactive interpreter
- `ide_editor` — editors/IDEs (VS Code, Thonny, PyCharm, Replit)
- `command_line` — terminal/shell basics
- `running_scripts` — running .py files, `python file.py`
- `comments` — comments & code readability
- `pep8_style` — style conventions, linting
- `tool_git` — git / version control
- `tool_pip` — packages, pip, virtual environments

## fundamentals
- `print_output` — print(), output
- `user_input` — input()
- `variables` — variables & assignment
- `data_types` — type concept, type()
- `integers_floats` — numeric types
- `arithmetic_operators` — + - * / // % **
- `type_conversion` — int(), str(), float() casting
- `booleans` — True/False, bool type
- `comparison_operators` — == != < > etc.
- `logical_operators` — and/or/not
- `expressions` — expressions vs statements, evaluation order
- `none_type` — None
- `constants` — named constants
